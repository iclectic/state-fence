# Contributing to StateFence

Thank you for your interest in contributing. This project is in its early stages, so the most valuable contributions right now are thoughtful API feedback, tests and documentation.

## Getting Started

1. Ensure Dart and Flutter are installed.
2. Clone the repository.
3. Run the checks in `AGENTS.md` before opening a pull request.

## Pull Request Process

1. Open an issue or discussion describing the change.
2. Keep each pull request focused on a single concern.
3. Add tests for bug fixes and new features.
4. Update relevant documentation, including `dartdoc` for public APIs.
5. Ensure `dart format`, `dart analyze` and tests pass.
6. Mark the pull request as ready for review.

## Code of Conduct

This project follows the code of conduct in `CODE_OF_CONDUCT.md`. All contributors are expected to treat one another with respect.
