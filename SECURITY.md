# Security Policy

## Supported Versions

Only the latest released version is supported with security updates. Pre-1.0 releases receive best-effort fixes.

## Reporting a Vulnerability

Please report security issues directly to the maintainers by email or a private message. Do not open a public issue for a vulnerability.

## What to Include

- A description of the vulnerability.
- Steps to reproduce, if possible.
- The version affected.
- Any suggested remediation.

## Scope

Security issues relevant to StateFence include any way to cause unbounded memory use, privacy leaks through diagnostic exports, or unsafe defaults in release builds.
